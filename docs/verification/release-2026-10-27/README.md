## 发布前视觉审查

按用户指定的替代型号使用三个 GPT-6.1 Sol 子代理独立审查 Web/Android 布局、原生 Mac、笔迹轮廓；主代理复核关键截图并修复。所有浏览器均使用独立上下文和合成工程，Mac 使用独立临时资料库。

- [手机与平板报告](visual-web/REVIEW.md)：72 张初始主截图及 4 张补图；修复后增加 108 张主截图及 4 张补图。覆盖 360/390、800、1100/1101、1280 宽度，资料库、A/B/对照、温故、校对、运行状态、全部设置、修订历史、字形学习和模型失败。无浏览器页面异常或文档横向溢出。
- 已修复两个 P2：竖屏平板对照 B 栏过窄，以及设置说明对比度不足。窄屏对照改为上下排列，宽屏保留并列；说明文字由 4.06:1 提升至 4.99:1。手机说明明确学习字形在平板操作。
- [原生 Mac 报告](visual-macos/REVIEW.md)：实际候选包主界面截图与 14 张源文件原生渲染截图分别标注。覆盖 960×640 主窗口以及列表、空态、搜索、温故、校对、A/B/对照、修订、历史、管理、设置和恢复。系统辅助功能不可用，补充界面由临时 NSHostingView 审查程序呈现，不冒称候选包完整点击或键盘验收。管理面板背景和搜索空态措辞已做最小修复并追加复查证据。
- [笔迹独立报告](visual-ink/REVIEW.md)：保留原来的二值轮廓断言失败，独立截图与像素分析未发现实质轮廓缺陷。不放宽阈值、不改变笔迹几何实现。

此轮审查沿用暖纸、深墨、灰紫与编辑式排版；没有重新设计产品。Android 截图来自模拟桥的真实 Chrome 渲染，不替代设备 WebView、实体笔、Android 系统对话框或设备字体矩阵。原生 Mac 的菜单、焦点、VoiceOver、低可用高度显示器和超长标签仍未穷尽验证；设置 sheet 在当前屏幕完整可见，不能把超出最小父窗本身误报为裁切。

## 已知例外与分发

完整 `npm run test:browser` 仍在既有 `tests/ink.browser.mjs:83` 停止：21/789＝2.6616%，高于 2% 阈值。旧/新表示边界存在抗锯齿差异，未发现缺笔、错位、内部空洞或完全不透明与完全透明像素互换。这一项作为明确记录的工程预发布例外保留，不能表述为完整浏览器套件通过。

发布附件为两个内容相同的 Android APK 下载入口和一个 arm64 Mac ZIP。设备原生角色区分权限；Android 调试签名、Mac ad-hoc 签名且未公证。SHA-256、最终源提交及包元数据由随发布上传的 `SHA256SUMS`、`MANIFEST.json` 给出。真实手写准确率、复杂公式、未知字形风格推断、实体笔和跨实体设备体验均不在本轮完成声明中。
