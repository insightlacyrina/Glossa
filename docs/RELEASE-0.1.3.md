# 笺注 · Glossa 0.1.3

端侧文字识别与 B→A 仿手写修订的工程预发布。

## 本轮更新

- Android 数字笔迹优先使用本机模型，支持简体中文、繁体中文与英文；模型由用户首次下载后离线使用。内置图片 OCR 随包提供，覆盖中英文。
- 同页相邻笔画成组识别，结果先进入校对候选。保留原稿和来源版本，不把模型置信度当作字符级映射。
- 平板框选单字全部笔画并确认字形后，修改已有 B 可在原位置生成可编辑矢量笔迹。压力、倾斜、时间等原始通道保留；压力参与当前笔宽渲染。
- 缺字、空间不足、公式等情况保留印刷修订层，并给出原因。补齐字形后可重试；人工改动过的修订不会被自动替换。支持局部擦除、独立撤销、合并、工程往返和同步。
- 手机与原生 Mac 可使用同步来的字形修订已有 B；原稿书写、字形学习和修订层管理由 Android 平板完成。
- 发布前修复竖屏平板对照挤压、设置说明对比度、手机操作提示，以及 Mac 管理面板和搜索空态的一致性问题。

## 下载

| 文件                                    | 使用范围                                          |
| --------------------------------------- | ------------------------------------------------- |
| `glossa-0.1.3-android-tablet-debug.apk` | Android 平板，Android 8.0+                        |
| `glossa-0.1.3-android-phone-debug.apk`  | Android 手机，Android 8.0+                        |
| `glossa-0.1.3-macos-arm64.zip`          | Apple Silicon Mac，macOS 14+；解压得到 Glossa.app |

手机与平板下载的是内容完全相同的 APK，原生端根据设备物理尺寸自动区分权限。不要通过改窗口或 URL 解锁平板权限。Android 包含 arm64-v8a、armeabi-v7a、x86 和 x86_64 原生库；Mac 本轮仅提供 arm64。

这是工程验证包：Android 使用调试签名，Mac 使用 ad-hoc 签名，尚未进行 Developer ID 公证。`SHA256SUMS` 和 `MANIFEST.json` 随附件提供。

## 验证与边界

完整 Node 回归 185 项、Swift 回归 20 项通过，Android 与 Mac 构建和签名核验通过。Android API 35 ARM64 模拟器的真实模型在线 29 项、缓存模型离线 27 项断言通过；这不代表实体笔质量或大规模中文准确率。

发布前视觉审查覆盖主要页面、空状态、长文本和新增识别／字形／修订弹窗，详细截图、审查结论和执行边界见 [本轮验收](verification/release-2026-10-27/README.md)。

完整浏览器套件仍有一项既有笔迹二值轮廓阈值检查失败：21/789＝2.6616%，超过原阈值 2%。独立目视与像素审查未发现实质轮廓缺陷，差异集中在边缘抗锯齿；本轮保留实现和原断言，以明确记录此项例外的方式进行工程预发布，不宣称全套浏览器测试通过。见 [笔迹审查](verification/release-2026-10-27/visual-ink/REVIEW.md)。

仿手写是已确认字形的确定性矢量复用，不会从少量样本推断任意未知汉字。真实触控笔、复杂公式语料、用户书写风格满意度和跨实体设备体验仍需专项评估。Office/iWork 无损往返等未实现目标保持原有边界。新字形操作需要参与同步的客户端一起更新。
