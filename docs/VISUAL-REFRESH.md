# 界面视觉优化 · 2026-10-22

保留暖纸、深墨、灰紫与编辑式排版，不调整 A/B 数据、原生文件、同步或恢复逻辑。

- 平板空页突出“一张新纸”；Mac/手机改为“把笔记带在身边”与直接“导入笔记”。不增加阅读端创建权限。导入继续使用原有文件校验与恢复确认。
- 温故区分无复习内容和今日暂无待复习；无数据时不再给完成对勾或跳转空知识列表。卡片计数命名为“全部复习内容”，避免误称全部领域知识块。
- 校对空页说明什么会进入待确认，并给出可用的笔记入口；笔记列表补齐冷启动、空文件夹和搜索无结果的引导。
- 顶栏显示实际模块或真实笔记路径，去除空页面的虚构层级；文件夹导航不再与所有笔记双重高亮。常态保存提示只出现在打开的笔记里，保存中、失败或只读等状态仍可见。
- 品牌中英文紧凑排列；底部三个工具均有文字，同步入口增加说明、箭头和悬停反馈；“最近打开”补充空提示。
- 统一模块标题与计数徽标，排期使用日历图标；英文调整为 REVISIT & REMEMBER、TRUE TO THE SOURCE。提高纸张插画和辅助正文对比度，补齐窄屏路径截断与侧栏滚动。

检查限于此次界面：生产构建、桌面/手机/开发平板八个视图的目视检查与入口检查。没有重跑旧的 Android/同步/文件恢复验收。两处已有浏览器脚本仅随新文案更新定位词。
