# 可执行验收与后续任务

本文以行为验收当前版本，避免把演示、内核单测或计划当作完整产品交付。自动化结果应附实际运行命令、时间和失败输出；未执行的项保持未验。

## 自动化入口

在项目根目录安装依赖后执行 `npm test`、`npm run build`。本轮具体结果由根代理在交付报告中记录；本文不预填通过数。

至少保留以下可复现测试类别：

| 类别           | 关键反例                                                          |
| -------------- | ----------------------------------------------------------------- |
| 数据模型和权限 | 手机/Mac 绕过 UI 调内核新建或结构操作必须拒绝                     |
| 精确映射       | 未确认识别不能被标为精确；引用缺失原对象不能悄悄成立              |
| 并发           | 同公式两字符并改全保留，同字符争夺保留双方并产生冲突              |
| 修订与撤销     | 后续人工笔迹不受 AI 撤销影响；有依赖操作不能盲撤                  |
| 合并           | 缺少不可逆确认不能合并；合并后来源与专用逆记录清除                |
| 原生格式       | 原文读入→改实际源对象→写回→重新读入，未知内容不应消失             |
| 动态关联       | 源缺失仍可编辑，恢复后非重叠传播，同对象冲突，超时冻结保内容      |
| 同步           | 真 HTTP，拒绝无授权，重复幂等，游标恢复，重启耐久化，错误模式拒绝 |
| 加密           | 错口令或篡改密文失败；不能回退明文或覆盖本地数据                  |
| 自动化         | 只处理 dirty 对象，开关独立，公式事实保护，未配置 OCR 不伪装成功  |
| 复习           | 固定/自适应可重复计算，断网自评生成下一次任务                     |
| 恢复           | 完整工程导出/导入，损坏文件拒绝，A/B/历史/关系/复习一致           |

## 本轮独立内核复核

审计代理实际执行 `node --import tsx --test --test-isolation=none tests/domain.test.ts`，当时版本为 **36 项通过、0 项失败**。这仅是内核的一次独立复核，最终全模块和浏览器结果以根交付报告为准。

审计最初复现的三个反例已修复并进入回归：相同值并行修订产生假冲突；删除 B 后遗留可见 A 修订层；A 内容编辑与并发删除静默丢弃编辑。另检查并补齐重复符号显式范围、过期冲突决议、引用图形描述保护、跨页新增字符不猜定位、有效修订跳转和不同 A 字段合流。真实 glyph 来源、同一 points 字段内的细粒度合并与仿手写生成仍属缺口。

## 人工验收脚本

每项记录实际系统、版本、设备、笔型号、网络条件、操作录像/截图、日志和结论。`未覆盖` 与 `失败` 要区别记录。

### A01 即开即写

首次打开与重启应用，确认进入一张固定纸张；无需先创建知识块。立即书写若干笔迹，离线刷新/重启后逐笔核对，不应强迫进入 AI/复习入口。检查界面没有充当教程的说明性小字。

### A02 平台权限

在 Android 平板创建笔记、纸张和块，编辑 A/B。在 Android 手机和 Mac 打开同一工程，修改已有块文字/公式、改标签和文件夹，做复习；确认不能创建笔记、加页、新增/删除/拆分/合并块，且调用内核接口也不能绕过。同步后在平板验证 B 修改生成 A 修订层。

### A03 固定纸张

分别创建 A4/B5/自定义比例、横竖方向和不同模板，写到页底确认不会无限延展；手动加页后原页尺寸与对象坐标保持。重新打开后仍相同。

### A04 真实笔迹

Android 真机以支持的笔书写轻重、不同倾斜、快慢线、连续公式和中文。保存后检查真实 pressure/tilt 与时间点，逐对象编辑并恢复；掌触、旋转、分屏、后台/前台不得意外画线或丢线。测量而不是主观声称低延迟。

### A05 编辑工具

图层开关与重排；框选/套索部分对象；局部擦除穿过一条笔迹；移动对象不影响无关对象；混排键盘文字；识别几何图形并撤销。每个未实现工具单列，不能用整条删除冒充局部擦除。

### A06 媒体和文档背景

插入图片、公式、截图、录音和资料，离线导出/恢复逐项可读；多页 PDF 作为固定背景批注后重新打开仍可定位原页。没有实现的媒体类型不得计入通过。

### A07 跨页知识块

在一页无块书写，再在两页选对象建立同一块。建立多个块并验证不嵌套，按授权在平板拆分/合并；源映射、复习记录与历史连续。手机/Mac 不提供这些结构操作。

### A08 逻辑关系

以手绘箭头表达关系，检查识别候选与不确定性。仅修改语义次序/关系时纸面坐标不变；建立跨笔记边，改名/移动文件夹后边仍有效。

### A09 归档与分类

创建两个文件夹及学科分类，让分类只选这两者；无候选则保持未分类。编辑旧笔记内容再归档，日期使用最后内容修改日期；标签/文件夹等管理操作不应伪装内容修改。

### A10 A/B 对应与校对

识别普通文字、公式、复杂图形和无法确认的笔迹。逐项核验原对象和字符身份；长按两侧进行跳转，跨页时定位正确。模糊区域必须保留原内容并进入校对，不能凭相近坐标显示已精确映射。仅 B 设备要能读取图形/原生对象的可用预览。

### A11 并行编辑与冲突

断开两设备，在同公式不同字符分别修改，恢复后两处修改都保留。再同时改同一字符，检查视觉冲突显示两个候选及原内容，用户选择后结果一致。增加并行插入/删除、编辑已删除字符和两设备离线删除对象反例。

### A12 修订生命周期

通过 B 修改手写内容，在原位置看到独立可编辑修订层；样本不足时印刷层可用。继续添加人工笔迹后独立撤销修订，人工笔迹保留。制造依赖操作检查预览。合并前取消确认不应改数据；确认后合并成为普通笔迹，检查来源区分及专用逆记录已清除，普通恢复仍可用。仿手写生成/重试单独验收。

### A13 增量后台任务

设置空闲时间，书写时不卡顿，停笔后任务只包含变化对象；继续书写后旧任务不能覆盖新内容；关闭笔记触发整理。独立开关各类任务并观察状态，未配置外部 OCR 要显示未配置/待校对，不能假装已识别。

### A14 内容保护

混合低/高置信错别字、疑似错误公式和错误事实。只允许高置信文字按规则更正并带可查可撤销标识；公式和事实保持，提示进入校对。候选、原因与原始范围可看。

### A15 API 与离线

首次配置兼容 API 时拒绝授权，确认没有数据发送；授权后只处理允许范围，撤销后停止。模拟无网、超时、401、429和坏响应，原始内容不丢；断网仍可完整写、看、管理、搜索和本地复习。

### A16 原生关联文件

Android 通过系统文件选择器选择 `.md` 和 `.tex`，读入实际源对象，插入纸张，分别从纸张和源修改并写回原文件，重新打开核对。源不可访问时继续编辑，恢复后写回；并发修改非重叠对象自动传播、相同对象视觉冲突。移动/改名后重新定位并核对身份；超过源离线期限才冻结为有内容的独立副本。删除关联对象时明确选择解除或删除源对象。对 Office/iWork 每种对象语义按覆盖表另测，不能据文本格式通过推定。

### A17 Mac 自托管同步

在真实 Mac 上启动独立服务器，设置认证和 HTTPS/私网安全入口。分别在局域网和另一互联网访问设备编辑；让 Mac 睡眠/断网，客户端继续本地工作并可见待同步，恢复后自动补齐 A/B 和对象历史。重启服务器检查备份。普通模式和 E2EE 分别验证，错误口令不可清空数据。Mac 明文 AI 代理未实现时不得提供假授权流程。

### A18 完整工程恢复与故障

准备跨页块、原始笔迹、未合并/已合并修订、冲突、关系、文件依赖、复习状态与待同步操作。导出后在隔离存储导入，逐项比较；无外部源访问也有可恢复快照。测试损坏包、存储配额不足、提交中途强制退出、异常重启和服务器日志损坏；未保存必须清楚提示，不能误报成功。

### A19 复习闭环

离线建立已有块复习计划，查看/调整负担、强度、考试目标，分别会/不会后检查下次时间变化。切换 A/B/对照，确保只自评、不自动判卷。逐平台检验系统通知、打开提示、任务中心、桌面小组件，缺一项单列。

### A20 可观测性

制造识别失败、未映射、同步失败、冲突、外部待写回和备份失败。用户能定位具体笔记、对象、原因、状态和可恢复动作；日志不泄露密钥或未经授权的内容。
